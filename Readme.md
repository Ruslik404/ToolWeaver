# 🤖 AI Helper (C#)

Простой консольный клиент на C# для общения с искусственным интеллектом через [OpenRouter API](https://openrouter.ai/). Отправляет запрос, получает ответ от LLM и выводит его в терминал.

## ✨ Возможности
- 🔹 Асинхронная работа с API (`async/await`)
- 🔹 Безопасное хранение ключей через переменные окружения
- 🔹 Автоматическая обработка JSON-ответов
- 🔹 Встроенная обработка ошибок сети и API

## 🛠 Требования
- [.NET 8 SDK](https://dotnet.microsoft.com/download) или выше
- Git
- API-ключ от [OpenRouter](https://openrouter.ai/keys)
